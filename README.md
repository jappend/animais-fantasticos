# Animais Fantásticos

Este projeto é um site puramente criado do zero com HTML, CSS e JavaScript como projeto final integrado no curso de JavaScript completo da Origamid.

O projeto conta com os seguintes aspectos:

- Um design moderno e responsivo;
- Atributos ARIA, o que permite uma acessibilidade maior ao site;
- Um código limpo, conciso e organizado;
- Integração com Webpack e Babel, o que possibilita uma compatibilidade consideravelmente maior;
- E muito mais...

Volta-se a frizar que cada elemento do site foi, sem exceção, estudado e criado do zero.

### English:

# Fantastic Animals

This project is a website built entirely from scratch using HTML, CSS, and JavaScript as the final integrated project in the Origamid Complete JavaScript course.

The project includes the following features:

- A modern and responsive design;
- ARIA attributes, which improve site accessibility;
- Clean, concise, and well-organized code;
- Integration with Webpack and Babel, allowing for significantly broader compatibility;
- And much more...

It is important to emphasize that every element of the site was, without exception, studied and created from scratch.
